## Origins of project code

- `research/calibration/xl330_calibration.[ch]`, `research/calibration/nv_read.[ch]`,
  `tests/stock_calibration.c`:
  - **Origin:** independently written from observed behaviour and data layout, not copied from ROBOTIS code. Owners
    confirmed this on 2026-11-20 ("Yes, from observation").
  - **Purpose:** project-written C that reads the servo's factory calibration table and settings journal, so the
    firmware reproduces the stock position mapping (factory-layout compatibility).
  - **Comments:** they describe the data format and layout (flash regions, headers, record layout) and the
    observed results. They carry no references into the stock program image. Address references were removed on
    2026-11-20 from these files and from `firmware/bridge.c` and `firmware/platform.c`.
  - **Contents:** no vendor code or vendor data.
- `tests/fixtures/synthetic-calibration.bin`: generated by
  `tests/fixtures/make_synthetic_calibration.py` from formulas; not derived from any device.
- `firmware/sensing.c` `temperature_lut[165]` (external-temperature lookup):
  - **Generation:** `tests/make_temperature_lut.py` builds it from an NTC thermistor model: 10 kΩ, Beta 3377.4 K,
    10.05 kΩ pull-up, nearest degree C. `test_native.sh` regenerates it and compares.
  - **Parameter origin:** a three-parameter fit to the temperature the servo reports for each ADC reading.
    No reference-thermometer data was used.
- All other files in the manifest: written for this project.
